🎮 El laboratorio secreto

Creá una habitación con tres objetos misteriosos. Al hacer clic sobre cada uno, debe pasar algo diferente. El objetivo es construir un minijuego simple, no uno enorme.

⏱ 45–60 min🧩 Sprites y objetos🖱 Evento de mouse💬 Mensajes
🎯 Tu misión

Un laboratorio esconde tres elementos: un cofre, una computadora y una puerta. Cada uno responde al clic con un mensaje. Después, agregá una reacción extra a uno de ellos.

🧠 Memoria rápida

Sprite = aparienciaEs lo que se ve en pantalla. Lo creás o dibujás desde el editor de sprites.
Objeto = comportamientoEs el que recibe eventos y ejecuta acciones.
Room = escenarioAllí colocás las instancias de tus objetos para jugar.

Lo que tenés que lograr

Al hacer clic sobre el cofre, aparece un mensaje y desaparece el objeto. La computadora muestra una pista. La puerta muestra una advertencia.

Esta simulación es una referencia visual. El videojuego real se construye en GameMaker.

🚀 Misiones para construirlo

1Prepará el escenario
  1. Abrí GameMaker y creá un proyecto nuevo con GML Code.
  2. Creá una Room o usá room1.
  3. Diseñá tres sprites sencillos: spr_cofre, spr_pc y spr_puerta.
💡 Recordá: no importa si los dibujos son simples. Lo importante es que se distingan.
2Creá los objetos
  1. Creá los objetos obj_cofre, obj_pc y obj_puerta.
  2. Asignale a cada objeto su sprite correspondiente.
  3. Arrastrá una instancia de cada objeto a la Room.
🧠 Una instancia es un objeto colocado dentro del escenario.
3Programá el clic del cofre
  1. Abrí obj_cofre.
  2. Agregá el evento Mouse → Left Pressed.
  3. Escribí este código:
show_message("¡Encontraste una llave secreta!");
instance_destroy();
🧠 show_message() abre una ventana con texto. instance_destroy() elimina esa instancia.

Ejecutá el juego y hacé clic en el cofre. ¿Qué ocurre?

4Hacé que los otros objetos respondan

En obj_pc, agregá Mouse → Left Pressed:

show_message("Pista: la puerta tiene un código.");

En obj_puerta, agregá el mismo evento:

show_message("La puerta está cerrada.");
💡 Los tres objetos comparten el mismo evento, pero cada uno puede hacer algo distinto.
5Tu toque personal

Elegí una de estas mejoras:

  • Hacer que otro objeto desaparezca después del clic.
  • Cambiar el texto para crear una historia propia.
  • Agregar un cuarto objeto con una nueva pista.

Probá tu cambio y comprobá que funciona.
